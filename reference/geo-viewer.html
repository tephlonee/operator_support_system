The .GEO file stores a flat 2D cut profile (outer contour and inner cutouts made of lines and arcs) plus the sheet thickness. This viewer rebuilds the solid by extruding that profile through the thickness. Weight assumes steel at 7.85 g/cm³. Bends, if any, are not stored in this file type.
